## Portfolio project

This portfolio is built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Publish with GitHub Pages

1. Create a GitHub repository for this project and push the project files to its `main` branch.
2. In the repository, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**.
3. Each push to `main` will build the site and deploy it to GitHub Pages. The first deployment may take a few minutes.

The Vite configuration automatically uses the repository path for project pages and the root path for a `username.github.io` repository. The local development server continues to use the root path.
